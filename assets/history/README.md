# История проекта

`v0.1.0_Open.png` — оригинальный рендер этого проекта из Git-тега `v0.1.0`,
путь в теге: `Tower_Bridge/renders/Tower_Bridge_Open.png`.
Он используется для сравнения исходной диорамы с расширенной городской сценой.
Происхождение и SHA-256 сохранены в `Tower_Bridge/evolution_validation.json`.
Ракурсы общего исторического сравнения различаются; сравнение последних двух
версий с одинаковыми камерами находится в `Tower_Bridge/renders/Before_After.jpg`.
