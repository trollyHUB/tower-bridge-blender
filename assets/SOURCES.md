# Original audio sources

`audio/tower_bridge_original.wav` is generated by `tools/create_presentation.py::synthesize` using Python standard-library arithmetic and a seeded pseudorandom generator (seed 1894). No recordings, samples, music or third-party sound assets are used. The project author may use and modify the generated audio with the project. The presentation manifest records the exact WAV hash.

Russian caption text is authored in `tools/create_presentation.py::CAPTIONS`. The local Windows Arial font is used only for rasterization and is not redistributed as a font file.
