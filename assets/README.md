# Ручная отделка

Исходные авторские библиотеки сохраняйте здесь отдельными `.blend`.
Сборка не записывает файлы в этот каталог. Итоговая процедурная сцена
пересоздаётся; ручные изменения результата сначала сохраните отдельной
библиотекой. Текущая версия полностью процедурная и не требует внешних ресурсов.
