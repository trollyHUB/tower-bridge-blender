# Что осталось после v1.2.0

**Все этапы текущего плана B00–B27 и E01–E05 завершены.**
После обновления лицензии Unity выполнены импорт, реальная сборка Windows
и проверка Player. Ранее открытые E05 / R12 / A13 закрыты результатами
`Unity/verification-status.json` и `Unity/Verification/`.

## Что проверено в Unity

Полный запечённый цикл, две отдельные створки, машины/колёса/двери,
запрет открытия при занятой дороге и закрытия при судне, посетитель на
створке, опора тротуара, запрет выхода в реку, столкновения CharacterController,
приближающийся автомобиль, камеры и управление освещением. Windows Player
реально запущен; четыре изображения получены из его камеры через WARP.
Это программный рендер и автоматизированная проверка PhysX, а не измерение
производительности видеокарты и не заявление о длительном ручном игровом тесте.

Интерактивный результат соответствует пробному этапу E05. Он использует
упрощённые материалы вместо узлов Blender, а движение контролируется
запечённым согласованным расписанием. Деформации воды и ткани Blender
не перенесены как покадровая сеточная анимация. Эти границы описаны в
[инструкции Unity](UNITY.md); они не скрыты за статусом завершения.

## Отдельные будущие решения

Владелец ещё не выбрал лицензию для собственного кода и моделей.
Публичный GitHub не назначает её автоматически. Это решение автора,
а не недоделанный этап сцены; разрешение на публикацию проекта уже дано.
Дождь, новые районы и расширение интерактивного прототипа сверх E05
могут стать следующим планом, но не добавляются задним числом в текущий.
