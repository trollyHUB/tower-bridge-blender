# План развития Tower Bridge Blender

Цель — живая городская диорама с согласованным движением машин, пешеходов и судов. Итоговая демонстрация: движение по мосту, остановка транспорта, разведение, проход парусника, закрытие, возобновление движения и вечерний финал.

Текущая версия — **v0.1.0**. Расширения ниже запланированы. Подробности: [полный план](PROJECT_PLAN.md), [сценарий](SCENARIO.md), [задачи](BACKLOG.md), [критерии](ACCEPTANCE.md). Входная страница — [документация развития](README.md).

## Что уже готово

- [x] Мост с башнями, двумя верхними переходами и боковыми подвесами.
- [x] Анимация центральных створок от 0 до 68°.
- [x] Проход парусника и движение камеры.
- [x] Процедурные материалы и анимация материала воды.
- [x] Три изображения Full HD и 30-секундный ролик.
- [x] Git, Git LFS, публичный репозиторий и релиз v0.1.0.
- [x] Автоматические проверки синтаксиса и JSON.
- [x] Документы требований, сценария, архитектуры и поэтапной разработки.

Автобусы, шлагбаумы и флаги остаются статичными в базовой версии. Люди, кварталы и физические источники света в фонарях ещё не созданы.

Версии обозначают последовательность результатов. При изменении объёма работ границы версий можно уточнить, сохранив обязательные критерии.

## Контрольные результаты

- [ ] **Транспортная версия:** обе полосы работают, мост открывается только после освобождения подвижных пролётов.
- [ ] **Расширенная дневная версия:** кварталы соединены с мостом, судно оставляет согласованный с движением след.
- [ ] **Вечерняя версия:** фонари освещают поверхности, пешеходы соблюдают перекрытие, окружение имеет умеренные движения.
- [ ] **Версия для портфолио:** нет заметных пересечений, видео соответствует сценарию и воспроизводится отдельно от Blender.

## Отдельное продолжение

Интерактивная версия в Unity развивается после готового Blender-проекта: управление мостом, время суток, камеры и прогулка по сцене. Подготовка к экспорту учитывается заранее; создание приложения не входит в обязательный результат v1.0.0.
