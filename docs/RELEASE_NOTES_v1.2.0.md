# v1.2.0 — дополнения живой сцены

- E01: короткая остановка автобуса с дверями, торможением и отдельной камерой.
- E02: дополнительный ролик с оригинальным звуком и русскими пояснениями.
- E03: отдельная бесшовная дневная водная петля 10 с/Full HD и её Blender-сцена.
- E04: ясная/пасмурная погода, три плотности машин и людей, независимые варианты.
- E05: после обновления лицензии проверены импорт, полный цикл Editor,
  Windows Player, прогулка и управление мостом; приложение и исходники включены.

Основной сюжет сохраняет 60 с,24fps,1920×1080, разводной мост,
согласованные машины/людей/суда и вечерний финал. Новая остановка автобуса
включена в основной монтаж. Геометрия, видео и переносимость проверяются
заново; [отчёт](IMPLEMENTATION_REPORT_v1.2.0.md) содержит область проверок.

Файлы: основной ZIP, `.blend`, немой и звуковой ролики, дневная петля,
обзорная копия, сравнительные изображения и отдельный Unity source ZIP.
Unity проверен на CPU WARP; упрощения материалов и область проверки
описаны в инструкции. Это интерактивный прототип, а не точная копия рендера Cycles.
